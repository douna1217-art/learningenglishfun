📚 如何给 Readiverse 添加新书

这个网站是一个文件夹，直接拖到 Netlify 就能部署。每个 topic（科目）是 books/ 里的一个文件夹。往里放书就行，不需要改动 index.html。

site/ ├─ index.html ← 首页（不用动） ├─ catalog.js ← 科目定义（很少改） └─ books/ ├─ fiction/ 空科目 ├─ science/ ├─ sel/ ← 里面已放好《The Lost Red Ball》 │ ├─ books.js 这个科目的书单 │ ├─ the-lost-red-ball.html 这本书本身 │ └─ the-lost-red-ball.jpg 封面 ├─ social-studies/ ├─ math-stories/ └─ history/

给某个 topic 加一本书

1把这本书的两个文件放进对应科目文件夹，例如 SEL 就放进 books/sel/：
· 书名.html（阅读器本身）
· 书名.jpg（封面图）
2打开那个科目的 books.js，在书单里加一段：
{ "title":"书名", "grade":"Grade 1", "subtitle":"简介", "readingBand":"Beginning Reader", "minutes":"8 min", "modules":["Listen","Read","Grammar","Vocabulary"], "cover":"books/sel/书名.jpg", "file":"books/sel/书名.html" }
3把整个 site 文件夹重新拖到 Netlify。首页会自动显示这本书，科目的数量也会自动更新。
💡 更省事的办法：把新书发给我，我直接给你一个该科目的压缩包（书 + 封面 + 已经写好的 books.js），你解压后整包丢进 books/对应科目/ 覆盖即可——完全不用手动改文字。

说明

因为 Netlify 是静态托管，网页无法自己“发现”你丢进去的文件，所以需要 books.js 这个书单登记一下。这是唯一需要登记的地方，其它都不用碰。
