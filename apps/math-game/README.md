# 乘法怪兽岛（独立小 App）

答对乘法题打败怪兽的小游戏。和英语网站（`site/`）完全分开，不会随英语网站一起部署。

这个文件夹自己就是一个完整的网站：字体、图标、离线缓存都在里面，不依赖其他文件。
可以装到手机桌面（PWA），第一次打开后没网也能玩。

## 免费放到网上（Netlify Drop）

1. 打开 https://app.netlify.com/drop
2. 把整个 `math-game` 文件夹拖进去
3. 几秒后会得到一个地址，例如 `https://xxx-123.netlify.app`
4. 免费注册一个 Netlify 账号把它保留下来（不注册的话，过一阵会被删掉）

注意：网站必须是 https 开头的地址，才能「装到手机桌面」和离线玩。

## 改了文件之后

改了这个文件夹里的任何文件，把 `sw.js` 里的 `VERSION` 数字加 1，
已经装好的手机才会拿到新版本。
